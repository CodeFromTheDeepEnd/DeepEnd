# t-SNE - Dimension Reduction for Visualization

This code implements t-SNE-algorithm from the scratch. It demonstrates the core structure and implements the mathematics explained in my blog post. 

Read the [Blog post](https://jani.isohanni.fi/dimension-reductions-t-sne/) for a detailed explanation of the concepts and the code.


## Installation & Usage

Run the code from the project root:
```bash

    python -m dimensionality_reduction.tsne.tsne
```
