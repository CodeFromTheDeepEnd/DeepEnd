# The Deep End - blog series code repository

I'm keeping a blog [TheDeepEnd](https://jani.isohanni.fi) from a variety of subjects. Some posts are more mathematical and they tend to have accompanying code to demonstrate the subject in hand. 
That code is stored in this repository.

Code examples are designed to be ran from the project root, for example:
```bash

    python -m deep_learning.autoencoder.ae_denoise
```
Snippets are usually short and self-contained. Larger pieces are on separate repositories.
